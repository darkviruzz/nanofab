# 8. Extended Feature Set (Target, Not Yet Implemented)

## 8.1 Inspection Step Insertion
- “Insert inspection after…” any step.
- Inspections produce artifacts and may populate metrology facets (e.g., thickness map).

## 8.2 Run Control
- Run entire chain or step-by-step.
- Pause/resume.
- Stop and mark partial completion.
- Operator confirmations (modal prompts).

## 8.3 Versioning of Parameter Sets
- Save parameter sets with versions.
- “Save as new version”, “revert”, “compare parameter sets”.
- Parameter set references stored as artifacts for traceability.

## 8.4 Branching and What-If
- Branch from a previous revision with modified parameters.
- Compare branches (requires `history.parents` support).

## 8.5 Multi-sample / Batch Mode
- Manage multiple samples in parallel (future).
- Shared recipe, per-sample run logs and artifacts.
