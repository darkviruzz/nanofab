# 12. Roadmap (Suggested Milestones)

1) **v0 (MVP)**  
   - file-backed run storage (revisions + artifacts)
   - robust `SampleState` schema + Quantity units
   - process chain editor + step executor + logs
   - artifacts browser (images + CSV)

2) **v1 (Metrology + Comparison)**  
   - inspection insertion
   - run comparison and metrics extraction
   - thickness maps and scalar metrology facets

3) **v2 (3D + Advanced Simulation Integration)**  
   - 3D viewer with measurement tools
   - plug-in simulation backends (Python solvers, FEM/RCWA hooks)
   - richer geometry/pattern references and overlays
