# 11. Glossary

- **Recipe**: the defined sequence of steps + parameter schemas.
- **Run**: an executed instance of a recipe for a specific sample.
- **SampleState**: snapshot of the physical sample (substrate + layers + facets + artifact refs).
- **Artifact**: persisted output (image/table/mesh/log) referenced by the state.
- **Facet**: extensibility block for future additions (metrology, simulation, geometry).
- **Gating**: prerequisite enforcement that blocks steps until dependencies are complete.
